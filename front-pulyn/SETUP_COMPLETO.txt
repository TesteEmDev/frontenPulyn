TROUBLESHOOTING RÁPIDO:

❌ "Connection refused 127.0.0.1:5432"
   → PostgreSQL não está rodando
   → Solução: net start postgresql-x64-16

❌ "password authentication failed"
   → Senha incorreta no .env
   → Verificar PGPASSWORD

❌ Frontend não conecta ao Backend
   → Backend não iniciou
   → Verificar console do backend por erros
   → Aguardar 15 segundos completos

❌ Migração falha
   → O backend executa migrations automaticamente
   → Se falhar, verifique os logs no console do backend

## 📱 CONTEXTO DO PROJETO

**Aplicativo:** Pulyn Family App (Flutter)  
**Backend:** Node.js + Express  
**Database:** PostgreSQL (Supabase)  
**Stack:** Flutter + Riverpod + Dio  

**URLs importantes:**
- Backend: `http://192.168.0.60:3001` ou `http://localhost:3001`
- API endpoint: `/api`
- Database: PostgreSQL via Supabase

3. **Riverpod** - Use providers corretamente para state management
4. **API calls** - Sempre com tratamento de erro adequado
5. **UX first** - Pense no usuário, não na facilidade do código
